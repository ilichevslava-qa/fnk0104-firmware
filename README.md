# fnk0104-firmware

OTA-канал прошивки умного ассистента на ESP32-S3 (FNK0104 / xingzhi-cube-1.54tft-ml307).

## Что внутри
- Радио (radio-browser), Каталог, Релакс (9 настроений)
- Аудиокниги LibriVox (только русские), продолжение с места
- Погода, Часы сна
- Будильник (3 слота, дни недели, Европа Плюс + плавное нарастание громкости)
- Таймер (пресеты 5/15/25/50)
- Голосовое управление будильником и таймером
- OTA-обновление с этого репозитория

## Как обновляется устройство
Прошивка проверяет `releases/latest`, сравнивает тег с собственной версией и,
если он отличается, скачивает asset `xiaozhi.bin` и перезагружается.

Обновить голосом: «обнови прошивку».

## Публикация новой версии
```powershell
powershell -ExecutionPolicy Bypass -File C:\esp\publish_ota.ps1
```
Скрипт проставляет версию вида `2026.10.24-1830`, собирает прошивку и создаёт релиз.
